# Preserved portfolio baseline: v0.5.2

Preserved on 20 November 2026 as a C Labs project snapshot.

- Android: QuickDrop Offline 0.5.2, versionCode 7.
- Linux: quickdrop-receiver 0.5.2, architecture all.
- QR scanner opens on a fresh launcher start; Scan laptop QR remains visible.
- Local QR pairing, remembered access, file streaming, resume and saved receipts.
- Parallel local address checks and visible pairing stages.
- Explicit unsuccessful connection messages instead of a prolonged silent wait.

The files in `releases/v0.5.2/` are the exact preserved binaries. SHA256SUMS and the release manifest record their identity. Source code is imported from the preserved source archive. Showcase documentation and repository housekeeping files were added around it; application source was not changed or rebuilt for preservation.

This is a preview baseline for demonstration and code review. HTTP remains unencrypted and the APK is debug-signed. See `docs/VERIFICATION.md` before making validation or platform-support claims.

The versioned files under `releases/v0.5.2/` preserve the native preview baseline. The repository root README links to its downloads and project documentation.
